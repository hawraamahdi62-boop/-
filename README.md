# درب التميّز 🇧🇭

برنامج تدريب على الاختبارات الوطنية للصف الثاني عشر (البحرين): رحلة بين معالم البحرين التراثية، مع شخصيات بحرينية، وموسيقى هادئة، وأصوات للإجابة الصحيحة والخاطئة، ولوحة للمعلمات.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية وتربط بقية الملفات |
| `style.css` | التصميم والألوان |
| `app.js` | البرنامج: المراحل، الأسئلة، الطالب، لوحة المعلم |
| `storage.js` | حفظ البيانات (localStorage في المتصفح) |
| `config.js` | رمز إدارة المعلمين |

## النشر على GitHub Pages
1. أنشئي مستودعاً جديداً على GitHub وارفعي الملفات الخمسة (مع هذا الملف) إلى الجذر.
2. من **Settings ← Pages** اختاري Branch: `main` والمجلد `/ (root)` ثم Save.
3. بعد دقائق يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

للتجربة محلياً: افتحي `index.html` في المتصفح.

## الاستخدام
- **المعلمة:** من "أنا معلم/ـة" اضغطي "🔑 إدارة المعلمين" وأدخلي الرمز من `config.js`، ثم أضيفي كل معلمة باسمها وكلمة مرورها. بعدها تدخل كل معلمة بكلمتها، وتضيف أسئلتها وتشاهد نتائج طلابها.
- **الطالب:** يكتب الاسم والصف والمدرسة، ويختار المعلمة والشخصية، ثم يبدأ. تُحفظ كل إجابة تلقائياً، وفي النهاية زر "إعادة البرنامج".

## ⚠️ حدود مهمة
- **التخزين محلي:** `storage.js` يحفظ في متصفح الجهاز نفسه. إذا حلّ الطالب من جهازه، فلن تظهر النتائج عند المعلمة على جهاز آخر. لجمع النتائج من أجهزة الطلاب يلزم قاعدة بيانات على الإنترنت (Firebase Firestore أو Supabase)؛ يكفي استبدال `storage.js` بمحوّل يقدّم الواجهة نفسها (`collection / doc / where / get / onSnapshot / set / delete`).
- **كلمات المرور ورمز الإدارة** تعمل داخل المتصفح فقط، وهي حماية بسيطة وليست أمنية.

## تعديل الأسئلة
أسئلة الهيئة والتدريبية في مصفوفة `BASE` داخل `app.js`، بالصيغة:
`B(رقم_المرحلة, 'المادة', 'نص السؤال', ['خيار1','خيار2','خيار3','خيار4'], رقم_الإجابة_الصحيحة_من_0)`
والمراحل في مصفوفة `ST`.
